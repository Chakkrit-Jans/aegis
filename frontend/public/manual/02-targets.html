คู่มือ WebGoat & Juice ShopWebGoat & Juice Shop Guide

แอปที่จงใจทำให้มีช่องโหว่ ไว้ฝึกเจาะระบบอย่างถูกกฎหมาย — เป็นเป้าหมายที่เหมาะสำหรับทดสอบ AegisDeliberately vulnerable apps built for legal hands-on practice — the ideal targets to exercise Aegis against.

1. แล็บสองตัวนี้คืออะไรWhat they are

🐐 OWASP WebGoat

แอป Java ที่สอนช่องโหว่ทีละบทเรียน มีคำอธิบายและโจทย์ให้ทำในตัว เหมาะกับการเรียนรู้เชิงลึกทีละหัวข้อA Java app that teaches vulnerabilities lesson-by-lesson, with built-in explanations and exercises — great for learning one topic at a time.

🧃 OWASP Juice Shop

ร้านค้าออนไลน์สมัยใหม่ (Node/Angular) ที่ซ่อน challenge กว่า 100 ข้อ มี Score Board ให้ไล่เก็บแต้ม เหมือนสถานการณ์จริงA modern web shop (Node/Angular) hiding 100+ challenges with a Score Board to track progress — feels like a real application.

💡 ทำไมสองตัวนี้Why these twoWebGoat = เรียนทีละช่องโหว่แบบมีเฉลย · Juice Shop = ฝึกภาพรวมเหมือนเจอเว็บจริง — ครอบคลุม OWASP Top 10 ทั้งคู่WebGoat = learn each flaw with guidance · Juice Shop = practice against a realistic whole app — both cover the OWASP Top 10.

2. กฎการใช้งานRules of use

⚠ สำคัญImportantรันสองแอปนี้บนเครื่อง/เครือข่ายของคุณเองเท่านั้น อย่าเปิดออกอินเทอร์เน็ตสาธารณะ และห้ามนำเทคนิคที่ฝึกไปใช้กับระบบผู้อื่นโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษรRun both only on your own machine/network, never expose them to the public internet, and never apply the techniques you practice to systems you don't own without written authorization.

3. ติดตั้ง WebGoatInstall WebGoat

  1. รันด้วย Docker — เปิดพอร์ต 8080 (แอป) และ 9090 (WebWolf)Run with Docker — expose 8080 (app) and 9090 (WebWolf). 
    docker run -d --name webgoat -p 8080:8080 -p 9090:9090 webgoat/webgoat
  2. เปิด http://localhost:8080/WebGoat → หน้า LoginOpen http://localhost:8080/WebGoat → the login page.
  3. สมัครผู้ใช้ใหม่ (Register new user) — WebGoat ให้สร้างบัญชีเองในเครื่อง แล้วล็อกอินเข้าเรียนRegister a new user — WebGoat lets you create a local account, then log in to start the lessons.
เข้าถึงจากภายนอกไม่ได้?Can't reach it from another host?WebGoat รุ่นเก่าผูกกับ 127.0.0.1 — ถ้า worker ยิงไม่โดน ให้บังคับ bind ทุก interface: เพิ่ม env -e WEBGOAT_HOST=0.0.0.0 -e WEBWOLF_HOST=0.0.0.0 ตอน runOlder WebGoat binds to 127.0.0.1 — if the worker can't reach it, force all-interface binding: add -e WEBGOAT_HOST=0.0.0.0 -e WEBWOLF_HOST=0.0.0.0 to the run command.

7. ให้ Aegis worker เข้าถึงเป้าหมายLet the Aegis worker reach the targets

Aegis รันเครื่องมือจากในคอนเทนเนอร์ worker ดังนั้น “localhost” ของ worker ไม่ใช่เครื่องคุณ มี 2 วิธีหลักให้ worker ยิงถึงเป้าหมาย: Aegis runs tools inside the worker container, so the worker's “localhost” is not your machine. Two main ways to make the target reachable:

วิธี A — ผ่าน host (ง่ายสุด แนะนำ)Option A — via the host (simplest, recommended)

รันเป้าหมายด้วย -p (อย่างในหัวข้อ 3 และ 5) แล้วในหน้า Aegis ตั้ง scope include เป็น host.docker.internal — เป้าหมายคือ host.docker.internal:3000 (Juice Shop) และ host.docker.internal:8080 (WebGoat) Run the targets with -p (as in sections 3 and 5), then in Aegis set the scope include to host.docker.internal — the targets become host.docker.internal:3000 (Juice Shop) and host.docker.internal:8080 (WebGoat).

วิธี B — เครือข่าย Docker เดียวกันOption B — same Docker network

เชื่อมคอนเทนเนอร์เป้าหมายเข้ากับเครือข่ายของ Aegis แล้วยิงด้วยชื่อคอนเทนเนอร์ Attach the target containers to the Aegis network, then target them by container name.

# หาเครือข่ายของ Aegisfind the Aegis network
docker network ls | grep aegis
# เชื่อมเป้าหมายเข้ามาattach the targets
docker network connect aegis_default juice-shop
docker network connect aegis_default webgoat
# แล้วตั้ง scope เป็นthen scope becomes  juice-shop:3000  ·  webgoat:8080

8. เช็คว่าพร้อมใช้Verify they're up

  1. จากเบราว์เซอร์ — เปิด http://localhost:3000 และ http://localhost:8080/WebGoat ต้องเห็นหน้าเว็บFrom your browser — open http://localhost:3000 and http://localhost:8080/WebGoat; both should load.
  2. จาก worker (แท็บ Terminal ใน Aegis) — ทดสอบว่าถึงเป้าหมาย:From the worker (Aegis Terminal tab) — confirm reachability: 
    curl -sI http://host.docker.internal:3000 | head -1
curl -sI http://host.docker.internal:8080/WebGoat | head -1
  3. เห็น HTTP/1.1 200 (หรือ 3xx) = worker ยิงถึงแล้ว พร้อมทำ Book 03Seeing HTTP/1.1 200 (or a 3xx) means the worker can reach them — you're ready for Book 03.
