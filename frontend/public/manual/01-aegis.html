คู่มือการใช้งาน AegisAegis User Guide

แพลตฟอร์มสั่งการทดสอบเจาะระบบด้วย AI ที่มี “คนอนุมัติทุกขั้นตอน” — ตั้งค่าครั้งเดียว แล้วเดินงานได้ตั้งแต่ต้นจนออกรายงานให้ลูกค้าAn AI-driven penetration-testing console with a human in the loop on every intrusive action — configure once, then run an engagement from scope to a client-ready report.

1. Aegis คืออะไรWhat is Aegis

Aegis เป็นระบบที่ให้ AI ทำหน้าที่ “ผู้ทดสอบเจาะระบบ” — มันวางแผน เลือกเครื่องมือ และวิเคราะห์ผลเอง แต่ทุกคำสั่งที่เป็น active/intrusive จะต้องหยุดรอให้คุณกดอนุมัติก่อน และถูกจำกัดด้วยขอบเขต (scope) ที่คุณกำหนด งานจบลงด้วยรายงานพร้อมหลักฐาน ผลกระทบ และวิธีแก้ Aegis lets an AI act as the penetration tester — it plans, picks tools, and analyzes results on its own, but every active / intrusive command pauses for your approval and is confined to the scope you set. An engagement ends with a report containing evidence, impact, and remediation.

🧠 AI ขับเคลื่อนAI-driven

วางแผนเป็นเฟส: recon → สแกน → ทดสอบ credential → ยืนยันช่องโหว่ → รายงานPlans in phases: recon → scan → credential testing → validation → reporting.

🚦 มีประตูกั้นGated

Scope Gate + Approval Gate กันการยิงนอกขอบเขตและกันการทำงานโดยไม่ได้รับอนุญาตA Scope Gate and Approval Gate stop out-of-scope or unapproved actions.

🧾 ตรวจสอบย้อนหลังได้Auditable

ทุกการอนุมัติ/คำสั่ง/การลบ ถูกบันทึกใน Audit LogEvery approval, command, and deletion is written to the Audit Log.

🛠️ เครื่องมือจริงReal tools

รันบนเครื่อง Kali จริง: nmap, nuclei, ffuf, hydra, ฯลฯRuns real Kali tooling: nmap, nuclei, ffuf, hydra, and more.

2. สถาปัตยกรรมArchitecture

ระบบแยกเป็นส่วน ๆ ผ่าน Docker: หน้าเว็บ (Next.js) → หลังบ้าน (Node/Express + Socket.IO) → เครื่อง Kali worker ที่รันเครื่องมือจริง โดยมี MongoDB/Redis เก็บสถานะ The system is split into Docker services: a Next.js web console → a Node/Express + Socket.IO backend → one or more Kali workers that run the real tools, with MongoDB/Redis holding state.

3. แนวคิดความปลอดภัย 4 อย่างFour safety concepts

① Scope Gate

ก่อนยิงเครื่องมือที่ระบุเป้าหมาย ระบบเช็คว่าเป้าอยู่ใน include และไม่อยู่ใน exclude — ถ้านอกขอบเขตจะถูกบล็อกทันที แม้ AI อยากทำก็ตาม Before any tool that names a target runs, Aegis checks the target is in include and not in exclude — out-of-scope targets are blocked immediately, even if the AI wants to proceed.

② Approval Gate

เครื่องมือทุกตัวที่เป็น active หรือ intrusive จะหยุดรอการ์ดอนุมัติ — คุณเห็นเหตุผลของ AI + คำสั่งจริง แล้วกด APPROVE / REJECT Every active or intrusive tool pauses on an approval card — you see the AI's rationale and the exact command, then APPROVE / REJECT.

③ Auto-approve

โหมดเสริม (checkbox ตอน spawn) ที่ปิดเฉพาะ “การอนุมัติของคน” เพื่อให้เดินเร็วในแล็บ — Scope Gate ยังทำงานอยู่เสมอ An opt-in mode (a checkbox when you spawn) that skips only the human approval so lab runs go faster — the Scope Gate still applies at all times.

⚠ ระวังCautionใช้ Auto-approve เฉพาะเป้าหมายที่คุณเป็นเจ้าของ/แล็บของตัวเองเท่านั้นOnly enable Auto-approve on lab targets you own or are explicitly authorized to hammer.

④ Audit + RBAC

ผู้ใช้มีบทบาท admin/operator; ทุกเหตุการณ์สำคัญถูกบันทึกถาวรและดูได้ที่ Settings → Audit Log Users are admin or operator; every significant event is recorded permanently and viewable in Settings → Audit Log.

5. ตั้งค่า AI ProvidersAI Providers

คือ “สมอง” ที่วางแผนและขับเคลื่อนงาน เพิ่มได้หลายตัว (DeepSeek / Anthropic / OpenAI-compatible เช่น Ollama) แล้วเลือกหนึ่งเป็น default — agent จะใช้ตัวที่เป็น default This is the reasoning engine that plans and drives engagements. Add several (DeepSeek / Anthropic / OpenAI-compatible such as Ollama) and mark one as default — the agent uses the default.

  1. ไปที่ Settings → AI Providers → + Add providerGo to Settings → AI Providers → + Add provider.
  2. เลือก provider, ใส่ API key (คีย์เก็บฝั่ง server ไม่โชว์กลับ), เลือก/พิมพ์ model แล้ว SavePick the provider, paste the API key (stored server-side, never echoed), choose or type a model, then Save.
  3. กด Set default ที่ provider ที่ต้องการใช้ และ Test เพื่อยืนยันว่าต่อได้Click Set default on the one to use, and Test to confirm connectivity.

6. ตั้งค่า Kali WorkersKali Workers

worker คือคอนเทนเนอร์ Kali ที่รันเครื่องมือจริง มีได้หลายตัวเพื่อแยกงานตามลูกค้า/เครือข่าย แต่ละ engagement เลือก worker ของตัวเองได้ หรือใช้ตัว default A worker is a Kali container that runs the real tools. You can register several to isolate work per client / network; each engagement can pick its own worker or use the default.

  1. Settings → Kali Workers → + Add worker ใส่ชื่อ, URL (เช่น http://worker2:7000) และ tokenSettings → Kali Workers → + Add worker, enter a name, URL (e.g. http://worker2:7000) and token.
  2. กด Health เพื่อเช็คว่าเครื่องมือครบ (เห็นจำนวน tools)Click Health to confirm the toolset is present (it shows a tool count).
🏢 EnterpriseCommunity รันได้ 1 worker · หลาย worker (แยกตามลูกค้า/เครือข่าย) ต้องใช้ Enterprise — ดู §17Community runs 1 worker; multiple workers (per-client/network isolation) needs Enterprise — see §17.

7. ตั้งค่าเสริม — Proxy & TelegramOptional — Proxy & Telegram

Proxy · Burp / Caidoส่ง web tool (nuclei, ffuf) ผ่าน proxy ดักจับ เพื่อเห็นทุก request — จาก worker เข้าถึง host ด้วย http://host.docker.internal:8080Route web tools (nuclei, ffuf) through an intercepting proxy so you see every request — from the worker reach the host via http://host.docker.internal:8080.

9. เดินงานเต็มรูปแบบ (ตั้งแต่ต้นจนจบ)A full engagement, end to end

  1. สร้าง Engagement — แผงซ้าย + New ใส่ชื่องาน + ลูกค้าCreate an engagement — left panel + New, enter a name and client.
  2. บันทึก Authorization — Record authorization ใส่ผู้อนุญาต + เลขอ้างอิง (ไม่ทำ = ยิงอะไรไม่ได้)Record authorization — Record authorization, enter who authorized it and a reference (without this, nothing active can run).

17. รุ่น & License (Community / Enterprise)Editions & Licensing (Community / Enterprise)

Aegis เป็น open-core: ตัวโปรแกรมหลักใช้ได้ฟรีในรุ่น Community และมี license ปลดล็อกความสามารถระดับองค์กรในรุ่น Enterprise — สถานะรุ่นแสดงเป็นป้ายข้างโลโก้ AEGIS มุมซ้ายบน Aegis is open-core: the core product is free as Community, and a license unlocks organization-grade capabilities as Enterprise. The current edition shows as a badge beside the AEGIS logo, top-left.

🛡️ หลักการสำคัญGuiding ruleฟีเจอร์ด้านความปลอดภัยทุกตัว (Scope Gate, Approval Gate, Audit Log) ฟรีตลอด ไม่มีวันอยู่หลัง paywall — เพราะเป็นเรื่องจริยธรรม ไม่ใช่ของขายEvery safety feature (Scope Gate, Approval Gate, Audit Log) is free forever and never behind the paywall — that is an ethics matter, not a product tier.

  1. กดปุ่ม ⓘ About (มุมขวาบน) → ส่วน Edition & LicenseClick the ⓘ About button (top-right) → the Edition & License section.
  2. วาง license key แล้วกด Activate Enterprise — ป้ายจะเปลี่ยนเป็น ★ Enterprise ทันที ฟีเจอร์ที่ล็อก 🔒 จะปลดล็อกPaste the license key and click Activate Enterprise — the badge flips to ★ Enterprise and 🔒 features unlock.
  3. กด Remove license เพื่อกลับเป็น Community เมื่อไรก็ได้Click Remove license to return to Community anytime.
🔑 License ทำงานอย่างไรHow licensing worksLicense เซ็นด้วยกุญแจ Ed25519 ของผู้ให้บริการ ตรวจสอบแบบ offline ในเครื่อง — ปลอมไม่ได้ (ไม่มีกุญแจส่วนตัวก็สร้าง license ไม่ได้) และ license ที่หมดอายุจะถือเป็น Community อัตโนมัติ · ผู้ให้บริการออก license ด้วย node licensing/sign-license.mjs "<องค์กร>" [วัน]Licenses are signed with the vendor's Ed25519 key and verified offline on the instance — they cannot be forged (no private key = no license), and an expired license reverts to Community automatically. The vendor mints one with node licensing/sign-license.mjs "<org>" [days].
